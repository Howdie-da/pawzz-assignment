> Product & Technology Intern Assignment Prototype

🌐 **Live Demo**: [https://pawzz-assignment.vercel.app/](https://pawzz-assignment.vercel.app/)

---

## 🌟 Overview

**Pawzz** solves the fragmented animal-care discovery problem in India. When pet parents or rescuers face an emergency or need everyday care for their dogs, cats, birds, or exotic pets, Pawzz connects them with verified vets, 24/7 clinics, ambulances, NGOs, and boarding facilities in one high-contrast, intuitive platform.

Built with a bold **Neo-Brutalism** design system inspired by [Ronas IT](https://ronasit.com/), featuring chunky tactile borders, hard zero-blur drop shadows, and saturated color pops.

## 🚀 Quick Start

### 1. Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.

### 4. Build for Production
```bash
npm run build
npm run preview
```

### 5. Run Linter
```bash
npm run lint
```

## 📱 Interactive Screens & Features

1. **Home & Discovery (`Screen 1`)**:
   - High-impact Neo-Brutalism hero headline with rotated highlight sticker.
   - Smart search bar with Bangalore location tag.
   - 6 quick-category interactive chips (Vets, 24/7 Emergency, NGOs, Ambulances, Boarding, Exotic Care).
   - Real-time stats ticker, featured nearby providers, and an AI feature teaser banner.
   - Floating emergency **SOS button** with pulsing brutalist alert rings and quick-call modal.

2. **Search Results & Map View (`Screen 2`)**:
   - Filter sidebar with species selector (Dogs, Cats, Birds, Exotic), category chips, sort options, and an "Open Now" brutalist toggle switch.
   - Interactive toggle between list grid and a **Blueprint Map View** with custom sticker pins.

3. **Provider Profile & Booking (`Screen 3`)**:
   - Comprehensive clinic detail page with verified badges, consultation fee, hours, and address.
   - Tabbed sections: **About**, **Services** (with checkmark stickers), **Reviews**, and **Medical Records**.
   - Interactive **Appointment Booking Modal** with form validation.
   - Direct CTAs for calling, directions, and records upload.

4. **AI Medical Record Reader (`Screen 4`)**:
   - Drag-and-drop prescription and lab report upload zone (supports PDF, JPG, PNG).
   - Built-in sample demo workflow (try without uploading a file!).
   - Multi-step animated processing pipeline with real-time status indicators.
   - Structured plain-language output: pet info, vitals breakdown, severity-tagged diagnosis, interactive medication schedule table, and red-flag alerts.
   - Option to save directly to the pet's digital health passport.
